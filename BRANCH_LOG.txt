Real API integration work for HR module endpoints (profile,
attendance, leaves), built against the Postman collection
("Mantic Erp"). Moved here from 1.0.0 on 2026-08-20.

- Leaves:

    /leaves path).

    unwired.
  - Added GetById (GetLeaveByIdUsecase, takes an int id) — plumbing
    only, unwired. Note: LeaveDetailView has no bloc yet, so wiring
    this later means giving that screen a bloc too.

    placeholder /ApplyLeave path with the wrong body shape). Request
    body now sends FromDate/ToDate/LeavePolicyId/Reason/
    AttachmentFileIds. Two open TODOs before this is fully correct:
      - LeavePolicyId is hardcoded null — the form's Sick/Annual/
        Other dropdown isn't wired to real policy ids yet (needs
        GetPolicies).
      - AttachmentFileIds is hardcoded [] — picked files aren't
        uploaded anywhere yet (needs a file-upload endpoint, likely
        Create (with attachment)).
