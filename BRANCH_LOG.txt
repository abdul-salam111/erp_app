BRANCH LOG

A quick summary of what work lives on which branch.

============================================================
production
============================================================

The main/default branch going forward. Created from the old main
branch and then brought up to date with 1.0.0 on 2026-08-20, so it
now matches 1.0.0 exactly. Used as the base for releases.

============================================================
staging
============================================================

Used for testing changes before they're considered stable. Has
earlier login/session and dashboard work that hasn't been folded
into 1.0.0 / production yet.

============================================================
1.0.1
============================================================

API integration work for the Profile, Attendance, and Leaves
sections. Moved here from 1.0.0 on 2026-08-20.

- Profile: basic setup done, not active yet.
- Attendance: monthly data integration done, not active yet.
- Leaves: balances and leave-details lookup set up but not active
  yet. Apply Leave is fully working, though it still needs the
  leave-type selection and attachments to be connected properly.

============================================================
1.0.0
============================================================

The main stable branch. Kept clean of the API integration work
above, which was moved to 1.0.1 on 2026-08-20.

Overall, this branch covers the app being built up from scratch:

- Initial project setup.
- Login and branch selection flow, with session handling so users
  stay signed in and get logged out properly.
- Role-based dashboards, so each user sees the screens relevant to
  their role.
- Accounts screen built out and polished.
- General app stability improvements — better error handling,
  smoother loading states, and a debug tool for checking API calls
  during development.
- Various housekeeping: app configuration, version updates, and
  iOS-specific setup (permissions, deployment settings).
